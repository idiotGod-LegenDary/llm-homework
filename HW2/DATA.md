# 数据来源与选择

原始项目：[THUCTC / THUCNews](https://github.com/thunlp/THUCTC)。本实验读取 [Tongjilibo 镜像](https://huggingface.co/datasets/Tongjilibo/THUCNews/tree/ae77e363396e90b54cdaa9eafdbc5e102a3d4019)，固定提交 `ae77e363396e90b54cdaa9eafdbc5e102a3d4019`。镜像的行服务显示 836,075 条，原项目介绍的数量约为 74 万；未宣称两者逐篇一致。

选择体育、财经、教育、娱乐、科技、房产、游戏、时政八个分类文件的前 1,250 条完整 JSONL 记录，共 10,000 条。类别取自源文件名，标题和正文由镜像分别提供。下载采用 HTTP 字节范围，保留读取前缀；每个实际保存前缀的长度、SHA-256、ETag、版本与 URL 均在 [download_manifest.json](results/download_manifest.json) 中。

这是固定文件前缀采样，不是从整个新闻总体随机采样，可能受新闻排序、时间和事件重复影响。处理规则事先固定：去除空白后正文不足 100 字、完整正文重复、前 200 字重复、分词后不足 50 词的文章被排除。文本去重不能排除所有同一事件的改写。

正文按句分割，用 jieba（HMM=False）分词，删除不含字母、数字或汉字等字母数字字符的标点 token，丢弃不足 3 词的片段。分类输入最多保留前 500 个词，始终不使用标题。

每类按 `SHA256("42|" + 类别/文件ID)` 排序，前 12 篇留作测试，接下来 48 篇作监督训练，其余为未标注预训练材料。**全部 96 篇测试文章在任何类别设置下都排除于词向量训练之外。** 2／4／8 类使用相同文章的嵌套子集。正文和前 200 字哈希均检查跨划分唯一。

逐篇 ID、源行号、正文哈希、前缀哈希、划分与词数见 [document_manifest.csv](results/document_manifest.csv)。标签是数据集主题类别，可能存在跨主题或原始标注问题，并非本次人工逐篇重新标注的金标准。

原始新闻、分词文本与模型保留在本地，由下载及实验脚本重新生成；公开仓库提供代码、校验清单、分数和少量错误示例，不上传完整语料。

公开结果表的标题和展示片段折叠空白以便阅读，分类输入、预测标签、概率和统计指标不变；原始新闻与本地运行材料保留。
