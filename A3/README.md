# A3：人民日报语料的 n-gram 训练、参数对比与续写

对应课件第 125 页：清理人民日报标注语料，训练不同阶数的 n-gram，比较训练时间，并从指定开头续写。

## 回答与主要发现

本实验使用 1998 年 1 月人民日报分词与词性标注语料，保留人工分词，清理记录编号、词性与复合实体标记，再用 KenLM 训练带 Modified Kneser–Ney 平滑的 2、3、5-gram。验证与测试按文章划分，并进一步去除完全相同的段落。三个阶数各训练三次，结果和日志随仓库保存，模型可由脚本重建。

阶数从 2 增加到 3，再增加到 5，测试 PPL 降低、训练时间和文件体积增加。3-gram 到 5-gram 的 PPL 改善幅度更小。指定提示的真实续写仍存在早停、搭配错误与主题偏离，说明新闻语料上的统计指标改善，不能直接代替对开放式生成质量的判断。

## 1. 数据来源、范围与版本

- 输入文件：`199801.txt`，UTF-8，10,666,468 字节；运行时通过 `--source` 指定。
- SHA256：`41760f40739b0f301ab29e99ab14565e7cd4b06128eb3a6ac18bce277a6075a8`。
- 原始 22,564 行，含 3,080 个空行；19,484 个非空段落、3,148 篇文章。
- 实验范围为 1998 年 1 月。
- 现有 README 将此数据描述为人民日报标注语料库 PFR。此文件与课程微信群指定版本是否完全相同，尚未通过文件哈希核验；这里明确记录实际使用的版本，便于后续核对。

### 为什么要清理 tag 和标签

本作业要学习的是原文词语的条件分布。若保留 `学校/n` 这样的标注形式，同一词的不同词性会变成不同 token，生成目标也变成带标记的文本；若保留段落编号，还会学习记录格式。训练输入和用户的普通文本提示之间因此出现不一致。

清理不意味着删除原有词边界：人工分词提供了本实验的 token 单位，应该保留空格。标点也是文本的一部分。本实验还保留全角数字、字母及真实的斜杠/括号，避免用“删掉所有非中文字符”破坏原文。

| 原始形式 | 处理结果 | 原因 |
|---|---|---|
| `19980101-01-001-001/m` | 删除训练文本中的编号，另存索引 | 编号用于追踪及划分文章 |
| `学校/n`、`摄/Vg` | `学校`、`摄` | 去掉词性，保留大小写形式的标签识别 |
| `[中央/n 人民/n 广播/vn 电台/n]nt` | `中央 人民 广播 电台` | 去掉实体包装，保持内部词边界 |
| `腾空而起/l/%` | `腾空而起` | 删除本文件观察到的附加标记 |
| `[/w`、`]/w`、`//w` | `[`、`]`、`/` | 保留作为正文标点的字符 |

实际移除 1,120,721 个词性标记、9,183 组实体包装、51 个额外 `/%` 后缀。清洗初次发现的 51 个错误均来自最后一种后缀；核查后只补充这项明确规则，最终解析错误为零，没有把异常行静默丢弃。

训练集清洗前的标注 token 类型为 57,601，清洗后的词语类型为 49,268。该对比说明表示发生了变化；本次没有训练一个保留标签的对照模型，不能据此给出“清洗使 PPL 改善多少”的因果结论。

### 划分与去重

取 `SHA256(20261008:article_id)` 的前 8 个十六进制字符转为整数，对 100 取余后分配：小于 80 为训练集，80—89 为验证集，其余为测试集。同一文章的所有段落归属同一集合。按训练、验证、测试的顺序删除相同词序列的段落，分别去掉 360、50、75 个重复段落，以减少完全相同文本跨集合出现。

| 集合 | 保留文章 | 保留段落 | 正文词 token | OOV token | OOV 比例 |
|---|---:|---:|---:|---:|---:|
| 训练 | 2,535 | 15,205 | 889,381 | 0 | 0.00% |
| 验证 | 287 | 1,725 | 100,721 | 3,541 | 3.52% |
| 测试 | 324 | 2,069 | 128,467 | 4,962 | 3.86% |

OOV 比例的分母为正文 token。评测工具还对每个段落加入一个 EOS，因此测试评分共 130,536 个 token，与表中正文数量不同。文章编号不重叠和精确去重不能排除相似新闻或模板内容造成的关联；本次没有进行近重复检测，也没有做跨月份测试。

## 2. 工具与训练设置

KenLM 的 `lmplz` 估计带 Modified Kneser–Ney 平滑的 n-gram，`-o` 控制阶数、`-S` 指定排序内存、`-T` 指定临时文件位置。[上游文档](https://kheafield.com/code/kenlm/estimation/)

实验使用的 Windows 可执行文件来自第三方 `ljh-sh/kenlm` v0.1.0 打包，上游项目是 `kpu/kenlm`。打包说明记录上游提交 `4cb443e`；工具归档 SHA256 已核验，详情见 `tools/tool_manifest.json`。这些文件不是上游官方发布的 Windows 二进制。

```text
lmplz.exe -o N -S 256M -T temp\
```

由脚本把同一份 `data/train.txt` 作为 stdin、把 stdout 保存为 ARPA。没有启用剪枝，也没有使用折扣回退参数。各轮顺序为 `2→3→5`、`3→5→2`、`5→2→3`；同一阶数三次构建的 ARPA 哈希一致。随后转换为 probing 二进制，用实际 `query.exe` 在验证和测试文件上评分。

运行环境：Windows 10，Python 3.12.14，NumPy 2.3.5，16 个逻辑 CPU。`256M` 是排序内存预算，并非整个进程的总内存上限。训练时间含读取语料、模型计算和写 ARPA，排除清洗、下载、文件哈希及二进制转换；缓存和系统负载会影响本机计时。

## 3. 真实训练与评测结果

每个阶数重复三次，时间为 wall time；PPL 为 query 输出中包含 OOV 的值，包含各段落的 EOS。

| n | 三次训练时间（秒） | 平均 ± 标准差（秒） | ARPA MiB | 二进制 MiB | 验证 PPL | 测试 PPL |
|---:|---|---|---:|---:|---:|---:|
| 2 | 3.797, 4.351, 3.617 | 3.922 ± 0.383 | 10.64 | 8.31 | 612.548 | 664.356 |
| 3 | 15.232, 16.024, 15.724 | 15.660 ± 0.400 | 35.75 | 22.68 | 494.596 | 547.342 |
| 5 | 27.922, 27.330, 26.885 | 27.379 ± 0.521 | 113.59 | 59.48 | 479.467 | 534.548 |

本次 2→3-gram 的测试 PPL 降低约 17.61%，3→5-gram 降低约 2.34%。高阶模型能保留更长的局部上下文，也需要处理更多 n-gram。结果符合当前数据与设置下的质量/资源权衡；没有比较其他平滑方法、其他训练规模或现代 LLM，不能据此确定所有场景的最佳阶数。

包含 OOV 的 PPL 是主表口径。排除 OOV 的测试 PPL 分别为 496.685、406.422、396.875，全部原始数值见 [evaluation.json](results/evaluation.json)。词表由训练集确定，没有用测试集补词表；不同 tokenization 和 OOV 处理之间的 PPL 不能直接比较。

## 4. 指定开头与不同参数续写

提示为：

```text
在阳光明媚的五月，我们学校胜利召开了
```

课件末尾的省略号作为待续写提示，没有送入模型。用训练词表的最长词匹配得到：

```text
在 阳光 明媚 的 五月 ， 我们 学校 胜利 召开 了
```

这 11 个 token 都在训练词表中。最长匹配只是本实验的输入切分约定，不等同于对任意中文句子都正确的分词器；该切分在三个模型之间保持一致。

### 参数与停止条件

每个阶数运行 greedy 一次，以及以下三种采样设置各三次，随机种子为 42、43、44：

- top-k=50、temperature=0.7。
- top-k=50、temperature=1.2。
- top-p=0.9、temperature=1.0。

最多生成 48 个新 token；遇到 EOS 立即结束。生成时不允许 `<s>` 和 `<unk>`，保留 EOS，采样概率在候选集中重新归一化。温度使用 `p^(1/T)`，top-p 在温度变换后的排序分布上累计，保留达到阈值的最小前缀。

KenLM 负责训练与评分。由于本次使用命令行工具，续写由 Python 读取真实 ARPA 概率及回退权重实现，没有把查询分数直接当作神经网络 logits，也没有手工改写生成结果。Python 的句子 log10 分数与 KenLM 对照，每阶 5 个验证段落，最大绝对差分别为 0.00012512、0.00001433、0.00004542，结果见 [分数核对](results/arpa_scorer_checks.json)。

### 部分原始输出

### 2-gram / greedy / seed=42

```text
在阳光明媚的五月，我们学校胜利召开了，在北京１月２１日电（记者王磊）
```

续写 11 个 token，停止原因为 EOS。

### 3-gram / greedy / seed=42

```text
在阳光明媚的五月，我们学校胜利召开了。
```

续写 1 个 token，停止原因为 EOS。

### 5-gram / top-k 50, T=0.7 / seed=42

```text
在阳光明媚的五月，我们学校胜利召开了话剧的编导与组织者、国家。
```

续写 8 个 token，停止原因为 EOS。

### 5-gram / top-k 50, T=1.2 / seed=42

```text
在阳光明媚的五月，我们学校胜利召开了《虎踞钟山》引起、全国政协主席李建国购车费一件，这是两条新闻媒介将把一年中，中国运动员创纽约股市和，以４．５
```

续写 37 个 token，停止原因为 EOS。


greedy 的 3/5-gram 在“召开了”后直接生成句号并结束，未补出自然需要的活动对象；提高温度改变了候选选择，但部分输出出现“召开了话剧”或混乱的人物/事件组合。已有样本支持“局部概率较高仍可能不合语义”的判断，不能凭少量固定提示断言某种采样策略普遍更好。

## 5. 代码理解与本次排查

`clean_line` 严格解析词/tag 和实体包装，遇到未识别格式先报错；`prepare` 按文章划分、精确去重并写来源索引；`train` 调用真正的 `lmplz` 并记录三次 wall time；`evaluate` 使用 `query` 的总体指标；`ArpaModel` 读取 log10 概率与回退权重；`generate` 在所得分布上解码。

本次排查了三个有实际证据的问题：清洗器遗漏 `/l/%`；日志中未经行首约束的 `OOVs` 搜索误匹配到 PPL 行；Windows 构建在管道 stdin 结束时抛出 error 109，改为普通文件输入后完成评分核对。最终使用成功的分析日志和 JSON，而没有把异常运行当成已完成结果。

代码调试与报告整理使用了大模型辅助；训练、评测和续写在本机运行，结果未作手工改写。

## 复现与目录

环境安装和数据准备见 [REPRODUCE.md](REPRODUCE.md)。在仓库根目录配置 Python 与 KenLM 后运行：

```powershell
python A3/run_experiment.py --source "path/to/199801.txt" --stage all --repeats 3
```

也可使用 PowerShell 入口：

```powershell
.\A3\run.ps1 -Source "path/to/199801.txt"
```

完整复跑会更新实验产物和计时记录。若需保留当前结果，可增加 `--output-dir A3/rerun`，将新产物写入单独目录。

| 路径 | 内容 |
|---|---|
| `run_experiment.py`、`run.ps1` | 实验入口 |
| `setup_kenlm.py`、`tools/tool_manifest.json` | Windows 工具安装与来源校验 |
| `results/实验结果.md` | 训练时间与 PPL |

完整语料、清洗后的数据、模型和工具二进制不纳入版本控制。发布副本仅把日志和命令记录中的机器绝对路径改为相对路径；数值、哈希和生成文本保持原值。
