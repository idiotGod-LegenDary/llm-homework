# 数据说明

使用人民日报 1998 年 1 月的人工分词、词性标注文件 `199801.txt`。原目录 README 将其称为 PFR 语料库，说明它由北京大学计算语言学研究所与富士通研究开发中心共同制作，原始新闻来自人民日报。

| 属性 | 值 |
|---|---|
| 编码 | UTF-8（可含 BOM） |
| 文件字节数 | 10,666,468 |
| SHA256 | `41760f40739b0f301ab29e99ab14565e7cd4b06128eb3a6ac18bce277a6075a8` |
| 原始行数 | 22,564 |
| 非空段落 | 19,484 |
| 原始文章数 | 3,148 |

复现实验时，从课程提供的语料或其他获准来源取得文件，通过 `--source` 指定位置。仓库没有复制完整语料或提供自动下载。

当前文件与课程微信群指定版本尚未逐字节比对。哈希不同意味着数据版本可能不同，训练时间、模型哈希和 PPL 也可能随之变化。清洗统计和划分后文件哈希见 [data_manifest.json](results/data_manifest.json)。

报告中只保留必要的格式示例和模型输出。
